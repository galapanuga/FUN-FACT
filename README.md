🤯 Fun Facts Manager

A simple, interactive web application that allows users to discover interesting facts, submit new facts, and manage submissions through a basic validation and approval system.

This project was created as part of the #MyFirstWebsite challenge to explore web development and experiment with AI-assisted coding using GitHub Copilot.

🚀 Project Overview

Fun Facts Manager is designed to make discovering and managing interesting information more engaging.

Users can explore facts from different categories, switch between dark and light themes, and submit their own interesting facts for review.

✨ Features

- Random Fun Facts: Discover interesting facts with one click.
- Fact Categories: Explore Science, Animals, History, and Space.
- Dark & Light Mode: Switch between two visual themes.
- Submit New Facts: Add interesting facts to the collection.
- Fact Validation: Check submissions for basic requirements and duplicates.
- Approval System: Approve, edit, or cancel pending submissions.
- Submission History: Track previous submissions and their statuses.
- Version History: Review changes made to submitted facts.
- Local Storage: Preserve application data in the browser.

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Interactive features and application logic.
- Local Storage – Browser-based data persistence.
- GitHub Copilot – AI-assisted development.

📱 How to Use

1. Open the website.
2. Choose a fact category.
3. Click Fakta Baru to discover another fact.
4. Select a category to submit your own fact.
5. Enter a fact that meets the validation requirements.
6. Submit it for approval.
7. Manage submissions through the history section.
